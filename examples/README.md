# latero examples

Example programs using the latero library. Each example is a standalone CMake project that links
against the **installed** library, so install latero first (see the [main README](../README.md)), then
build an example from its own folder.

- [01-vibrate-loop](01-vibrate-loop): makes the pins of the Latero vibrate with a simple loop.

More examples, using the latero-graphics library, are in
[latero-graphics/examples](https://github.com/OpenLatero/latero-graphics/tree/master/examples).
